# Task 4 — Trend Analysis by Release Year

## Overview
Analyze Netflix content records by release year using Python and Pandas to identify trends and changes over time.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Findings
- The dataset contains records across 74 distinct release years.
- 2018 has the highest count, with 1,146 records.
- Content counts increased substantially during the 2010s.
- Counts declined from 1,030 in 2019 to 592 in 2021.

## Deliverables
- Completed Jupyter Notebook
- `yearly_content_trend.png`
- Yearly content counts
- Year-to-year change analysis
- Business insights summary

## Data Limitation
These results describe the cleaned dataset and do not directly measure Netflix's annual production or platform additions. Dataset coverage may affect the observed trends.
