# Task 5 — Content Rating & Genre Analysis

## Overview

Analyze Netflix content ratings and genres to understand catalog classification and compare Movies with TV Shows.

## Tools Used

- Python
- Pandas
- Matplotlib
- Plotly
- Jupyter Notebook

## Key Findings

- TV-MA is the most common rating, with 3,205 records.
- TV-14 is the second most common rating, with 2,157 records.
- International Movies is the most common genre/category, with 2,752 records.
- Dramas rank second, with 2,426 records.
- TV-MA and TV-14 are the most frequent ratings for both Movies and TV Shows in the dataset.

## Data Limitation

Genre categories may overlap because a title can have multiple genres. Category frequencies do not directly measure audience preferences or viewership.
