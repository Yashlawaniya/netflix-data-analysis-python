# Task 3 — Country-Wise Netflix Content Analysis

## Overview

Analyze Netflix content records by country to identify the leading countries, create rankings and visualizations, and generate business insights using Python and Pandas.

## Objectives

- Clean and inspect country information.
- Calculate country-wise content counts.
- Identify and rank the top 10 countries.
- Create and export a horizontal bar chart.
- Summarize key business insights.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Findings

- The United States ranks first with 3,240 records.
- India ranks second with 1,057 records.
- The United Kingdom ranks third with 638 records.
- The analysis includes 8,503 records with non-missing country values out of 8,790 total rows.

## Deliverables

- Completed Jupyter Notebook
- `top_10_countries.png`
- Country ranking table
- Business insights summary

## Data Limitation

The results reflect the current cleaned dataset. Missing or transformed country information may affect the counts, so these results should not be treated as definitive measures of original production by country.
